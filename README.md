# Flappy Bird Web Game

A simple HTML/CSS/JavaScript implementation of Flappy Bird.

## Files
- `index.html` — game UI and canvas
- `style.css` — styling
- `script.js` — game logic
- `.devcontainer/` — GitHub Codespaces dev container config

## Run locally
1. Open `index.html` in your browser.
2. Click or press `Space` to start and flap.
